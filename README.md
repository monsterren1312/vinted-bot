# Vinted Telegram Bot

Telegram-бот, который каждые пару минут проверяет **vinted.de** и присылает новые объявления
по выбранным брендам и цене. Продавцы без отзывов (новые аккаунты) пропускаются.

## 📱 Приложение (Telegram Mini App)

Кнопка **«📱 Приложение»** слева от поля ввода (или `/app`) открывает полноценное приложение внутри Telegram:

- **🔥 Новые** — сетка найденных объявлений с фото, фильтр по бренду, карточка объявления (открыть на Vinted, в избранное, скрыть продавца).
- **📋 Фильтры** — список с переключателями вкл/выкл; редактор: бренд с подсказками, регион (🇪🇺 / 🇬🇧 / оба), цена, слова, категория, состояние.
- **🕐 Период** — объявления за 1 / 3 / 6 / 24 часа по всем фильтрам или по одному.
- **❤️ Избранное** и **⚙️ Ещё** — настройки, тихие часы, минимум отзывов, скрытые продавцы.

Как это устроено: бот поднимает веб-сервер на `127.0.0.1:8787`, а отдельный сервис автозапуска
`com.vinted-bot.tunnel` держит бесплатный туннель Cloudflare (`bin/cloudflared tunnel --url …`) с публичным адресом
`*.trycloudflare.com`. Туннель отделён от бота, поэтому перезапуск бота адрес не меняет; новый адрес появляется только
после перезагрузки Mac — бот сам узнаёт его у cloudflared (`127.0.0.1:20241/quicktunnel`) и обновляет кнопку меню.
Все запросы приложения проверяются подписью Telegram (initData), поэтому чужой человек со ссылкой ничего не увидит.

Если приложение открывается белым экраном — Telegram держит старую ссылку: закрой чат с ботом и открой снова,
или отправь `/app` (кнопка в ответе всегда со свежей ссылкой).

Установка cloudflared (macOS, Apple Silicon):

```bash
mkdir -p bin && curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-darwin-arm64.tgz | tar -xz -C bin
```

Без `bin/cloudflared` бот работает как раньше, просто без приложения.

## Меню в боте

Всё управляется кнопками — `/start` открывает главное меню, а внизу всегда есть кнопки
«🔥 Новые», «📋 Фильтры», «➕ Бренд», «❤️ Избранное», «🏠 Меню».

**Фильтры**
- **➕ Добавить бренд** — 3 шага: бренд (кнопкой или напиши название) → регион (🇪🇺 Европа, 🇬🇧 Англия или оба сайта) → цена (готовые варианты или свой диапазон, например `10-50`).
- **📋 Мои фильтры** — 🗑 рядом с фильтром удаляет его одним нажатием; «Выключить все / Включить все», «Удалить все».
- **Карточка фильтра** — 💶 цена, 🌍 регион, 🔎 слова в названии (например `dunk`), 👕 категория (мужская/женская одежда, обувь, аксессуары, сумки, «все аксессуары и сумки», «вся обувь», детское…), 📏 размеры (одежда XS–XXXL, брюки W28–W38, обувь EU/UK — можно сочетать), ✨ состояние (можно отметить несколько), 🔥 всё найденное по фильтру, вкл/выкл, удаление.

**Объявления**
- Каждое новое объявление приходит с фото и кнопками: 🛒 открыть на Vinted, 🤍 в избранное, 🚫 скрыть продавца.
- **🔥 Новые** — лента всех найденных объявлений, листается ◀️ ▶️.
- **❤️ Избранное** — сохранённые объявления.
- **🔄 Проверить сейчас** — не ждать следующей проверки.
- **🕐 Объявления за период** — всё, что выставили за последний 1 / 3 / 6 / 24 часа, по всем фильтрам или по одному (кнопка в карточке фильтра). Vinted не отдаёт время публикации, поэтому бот оценивает его по номеру объявления (номера растут со временем) — время примерное (≈).
- Если объявление подходит под несколько фильтров, оно придёт один раз.
- Старые объявления, которые продавец «поднял» наверх, не присылаются — только действительно новые.

**Настройки**
- **👤 Минимум отзывов у продавца** — 0 / 1 / 5 / 10 / 50.
- **🌙 Тихие часы** 23:00–08:00 — ночью без уведомлений, найденное сохраняется в ленту.
- **🚫 Скрытые продавцы** — вернуть скрытых продавцов.
- **⏸ Пауза** — временно выключить уведомления.

Быстрая команда тоже работает: `/add nike 10-50`.
После добавления или изменения фильтра бот запоминает текущие объявления и присылает только те, что появятся **после**.

## Настройка

1. Создай бота у [@BotFather](https://t.me/BotFather) и возьми токен.
2. Скопируй `.env.example` в `.env` и впиши `TELEGRAM_TOKEN`.

| Переменная | По умолчанию | |
|---|---|---|
| `TELEGRAM_TOKEN` | — | токен бота (обязательно) |
| `CHECK_INTERVAL` | `120` | интервал проверки, секунды |
| `MIN_FEEDBACK` | `1` | минимум отзывов у продавца по умолчанию (меняется в ⚙️ Настройках) |
| `ALLOWED_CHAT_IDS` | пусто | кому можно пользоваться ботом (id через запятую); бот покажет твой id на `/start`, если доступ закрыт |
| `VINTED_DOMAIN` | `www.vinted.de` | регион по умолчанию (в меню можно переключить на vinted.co.uk) |

## Запуск

Локально (Python 3.9+):

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
set -a; source .env; set +a
.venv/bin/python bot.py
```

Docker:

```bash
docker build -t vinted-bot .
docker run -d --restart unless-stopped --env-file .env -v $(pwd)/data:/app/data vinted-bot
```

Бот должен работать постоянно, поэтому его нужно запустить на сервере (VPS, Railway, Fly.io, Render
и т.п.) или на своём компьютере. GitHub хранит код, но GitHub Actions не подходит для постоянно
работающего бота (cron там не чаще раза в 5 минут и с задержками, бот не сможет отвечать на команды).

## Как это работает

- Vinted больше не отдаёт `/api/v2/catalog/items`, поэтому список объявлений берётся из страницы
  каталога (`/catalog?brand_ids[]=…&order=newest_first&price_from=…&price_to=…`).
- Бренды ищутся через `/api/v2/brands`, отзывы продавца — через `/api/v2/users/{id}` (кешируется на 6 часов).
- Состояние (фильтры и уже виденные объявления) хранится в SQLite `data/bot.db`.
- Vinted защищён от ботов (DataDome). С домашнего IP всё работает; IP дата-центров иногда блокируются —
  в этом случае в логах будут ошибки 403.

## Автозапуск на Mac

```bash
./autostart-mac.sh          # включить (нужен токен в .env)
./autostart-mac.sh remove   # выключить
```

Бот стартует при входе в систему, перезапускается при сбоях и не даёт Mac уснуть, пока работает (при закрытой крышке ноутбук всё равно уснёт). Лог: `data/bot.log`.
